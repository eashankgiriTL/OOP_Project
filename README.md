# Hospital Management System (Java OOP Project)

## Description
A console-based Hospital Management System developed using Java OOP concepts.

## Modules
- Patient Module
- Doctor Module
- Consultant (Appointment) Module
- Reception / Billing Module

## OOP Concepts Used
- Classes & Objects
- Encapsulation
- Inheritance
- ArrayList
- Exception Handling
- Menu-driven program

## How to Run
1. Compile: javac *.java
2. Run: java HospitalManagementSystem
